Hole position is a percentage of the plaque measured from the top-left of the picture, so it stays put if you resize. It is punched through after the colours are decided, so it removes material without shifting anything, and it shows as grey in the simulated print because it is a void rather than black filament.

Dot size = how wide one square of the picture is on the print. It sets how accurately edges are placed, and sampling finer than the nozzle genuinely helps there — a 0.4 mm bead still follows a path positioned to about 0.01 mm, so finer dots give smoother boundaries. What the nozzle limits is different: the smallest island that can exist at all. Anything narrower than one bead is dropped by the slicer no matter how fine the dots. Dots sharpen what survives; plaque size decides what survives. File size grows as 1/dot².
Interlayer = black layers between channel bands, so each band's gradient reads against fresh black instead of the colour below it. Set 0 to disable.
